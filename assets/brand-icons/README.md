# Cached printer brand icons

These SVG files are fetched at development/release time by `scripts/cache-brand-icons.sh`. The dashboard serves only these local copies and never contacts Iconify from a visitor's browser.

| Local file | Iconify collection/icon | Collection license |
| --- | --- | --- |
| `bambu-lab.svg` | `simple-icons:bambulab` | CC0-1.0 |
| `prusa-research.svg` | `thesvg:prusa-research` | MIT (see `THESVG-LICENSE.txt`) |
| `creality.svg` | `simple-icons:creality` | CC0-1.0 |
| `generic.svg` | Original project artwork | Project license |

Brand names and logos may also be trademarks of their respective owners. They are used only to identify the corresponding printer manufacturer.
